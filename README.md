An e-commerce web app that allows users to browse products, search by 
category, manage carts, and place orders. Admins can manage inventory, track 
orders, and control access through a secure dashboard. 
Key Features 
• Backend using C# with ASP.NET Core MVC and SQL Server via EF Core 
• Responsive UI built with Bootstrap 5, jQuery, and Font Awesome 
• Category-based product catalog with search and cart management 
• Admin dashboard for inventory control and order tracking 
• Secure admin login with session timeout; customer portal planned 
• Role-based access and user account management
